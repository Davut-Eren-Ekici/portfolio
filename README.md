# 💻 Davut Eren Ekici | Portfolio

Kişisel portföy web sitem.

Bu proje, web geliştirme alanındaki bilgilerimi, öğrendiğim teknolojileri ve geliştirdiğim projeleri sergilemek amacıyla oluşturduğum kişisel portföy sitesidir.

## 🌐 Canlı Demo

[Portföyümü Görüntüle](https://davut-eren-ekici.github.io/portfolio/)

## 🚀 Özellikler

- 📱 Responsive tasarım
- 🧭 Sticky navigasyon menüsü
- 👨‍💻 Hakkımda bölümü
- 🛠️ Teknolojiler bölümü
- 📂 Projeler bölümü
- 📩 İletişim bölümü
- ✨ Hover efektleri
- 🎬 AOS animasyonları
- 🪟 Teknoloji kartları için interaktif modal sistemi
- 📱 Mobil uyumlu navbar

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- AOS (Animate On Scroll)
- Git
- GitHub

## 📚 JavaScript ile Eklenen Özellikler

Bu projede JavaScript kullanarak:

- DOM elementlerini seçme
- `querySelector()`
- `addEventListener()`
- Fonksiyonlar
- Parametreler
- `textContent`
- `innerHTML`
- CSS özelliklerini JavaScript ile değiştirme
- Modal oluşturma ve kontrol etme

konularını uygulamalı olarak kullandım.

## 🎨 Tasarım

Site koyu tema üzerine tasarlanmıştır.

Teknoloji kartlarında kullanılan ikonlar Devicon üzerinden alınmıştır.

Site, masaüstü ve mobil cihazlarda düzgün çalışacak şekilde responsive olarak tasarlanmıştır.
